## Features

✅ Mouse Testing

- Left / Right / Middle click
- Polling rate
- Scroll wheel
- Coordinates
- Pressure
- Stylus support

---

✅ Keyboard Testing

- NKRO
- Key history
- Key duration
- Live key visualization
- Persistent max NKRO

---

✅ Touch Testing

- Multi-touch
- Finger tracking
- Canvas visualization
- Haptics API

---

✅ Controller Testing

- Xbox
- PlayStation
- Generic HID
- Analog sticks
- Buttons
- Rumble

---

## Technology

- React
- Vite
- TailwindCSS
- Browser APIs

## Installation

```bash
git clone https://github.com/ddhairyashahofficial/webtool-peripheral-tester.git

cd webtool-peripheral-tester

npm install

npm run dev
```
